# Agentic guides

PyFly's opt-in Agentic module provides agents, tools, model routing, content,
knowledge retrieval, reasoning, validation, pipelines, workflows and operational
controls under `pyfly.agentic`.

Start with the [module overview](../agentic.md), [installation](getting-started/installation.md),
and [native runtime tutorial](native-runtime.md). The [guide catalogue](catalogue.md)
links every capability and the [example catalogue](examples.md) distinguishes
local exercises from provider and infrastructure requirements.

The public capability guides preserve the standalone implementation's algorithms
and limitations. Native integration changes package ownership, application state,
configuration, discovery and lifecycle. See [migration](migration.md) before moving
an existing application. The standalone [dependency record](dependency-upgrade-26101.md)
and [changelog](changelog.md) are explicitly historical.
