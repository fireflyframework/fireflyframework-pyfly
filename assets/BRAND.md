# Official family identity

`docs/assets/pyfly-banner.svg` and `docs/assets/pyfly-logo-{light,dark}.svg` come from the shared
2026-10-08 Firefly Framework brand kit, `Framework-Brand-Kit/12-Frameworks/python/`.
Their typography is outlined; rendering requires no fonts or external assets.
The dark-surface logo is configured for the documentation header, whose background
is dark in both reader themes. The README and public landing page use the same
family identity from the repository's top-level `assets/` directory.

`pyfly-book-cover.svg` is a byte-identical copy of `book/art/cover.svg`, used by
the public landing page. Refresh it when updating the English book artwork;
the canonical source and delivered hashes are recorded in `book/art/PROVENANCE.md`.

Framework import names, package names and technical documentation remain unchanged.

The public and book diagrams use the same palette and outlined family lockup.
Their geometry-preservation record and maintenance commands are in
`book/art/PROVENANCE.md` and `book/art/diagram-branding.json`.
